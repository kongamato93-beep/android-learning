## 二、在 Word 里的实际操作（30 秒一张）

1. `Ctrl+F` 搜「此处插入」，定位到红色占位符；
2. 选中这一整行删掉（**别删下面那行图注**）；
3. 光标停在该位置 →「插入 → 图片 → 此设备」→ 选 `docs/screenshots/figN_xxx.png`；
4. 图片右键「大小和位置」→ 取消「锁定纵横比」不用管，直接改**宽度**（表格里给了建议值），高度会自动跟着变；
5. 图片段落设为**居中**，环绕方式用默认的「嵌入型」；
6. 图注那行也居中（模板里已经设好了）。

**排版建议**：图 1、图 4 是评分重点，一页放一张，别挤；图 2、图 3、图 7 可以两张挤一页。
宽度超过 7cm 时一页基本只能放一张图，报告会多出 3–4 页，双面打印记得算纸。

## 三、如果要自己重拍（比如想用真机）

现成截图是 Pixel 6 模拟器（Android 17，1080×2400）截的，换成你自己的手机重拍也完全可以，只要内容一致。

```bash
# 1. 装包并启动
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell monkey -p com.example.wechat 1

# 2. 切到想要的 Tab（四个 Tab 在屏幕底部的横坐标约为 135 / 405 / 675 / 945）
adb shell input tap 135 2258     # 微信
adb shell input tap 405 2258     # 通讯录
adb shell input tap 675 2258     # 发现
adb shell input tap 945 2258     # 我

# 3. 截图
adb exec-out screencap -p > fig1.png
```

拍 Toast 要卡时间：Toast 只显示约 2 秒，**点击后 0.25 秒左右**再 screencap 才抓得到；
uiautomator dump 是抓不到 Toast 的（它属于系统窗口），别在这上面浪费时间。

拍「我」页之前最好确认顶部显示的是 **5120244700**（实验三登录的那个账号）。如果之前点过别的账号，
清一下数据再进：`adb shell pm clear com.example.wechat`。
